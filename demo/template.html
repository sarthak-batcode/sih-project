About this demo

What this file is, and what it is not.

This is the real model, not a mock-up. The selected classifier is a logistic regression, so the whole thing is 25 coefficients, a scaler and a one-hot encoder. Those were exported from ml/saved_models/best_model.joblib and are evaluated here in JavaScript. A score you read on this page matches what POST /api/v1/predict returns for the same inputs, to four decimal places.
No network, no install, no server. Open the file and it works — on a laptop with no Python, no Node, and no connection. It exists so a demo survives a dead venv, a broken npm install or a hall with no Wi-Fi.
What it leaves out. Authentication, RBAC, the audit ledger, the SQLite database, operator-configurable thresholds and the governance screens all live in the full stack. There is no login here because there is nothing to protect — the data is synthetic and the file is read-only.
The data is synthetic. 100 generated zones and 15,000 generated complaints, seeded at RANDOM_SEED = 42. No real complaint, person, account or location appears anywhere in this project.
